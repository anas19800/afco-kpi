# AFCO KPI (Next.js 14 + Prisma)
Quick-start package. Steps:
1) `cp .env.example .env.local` and edit DATABASE_URL
2) `pnpm i`
3) `pnpm prisma migrate dev`
4) `pnpm prisma db seed`
5) `pnpm dev` => http://localhost:3000
